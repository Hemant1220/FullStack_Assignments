From a URL to a visible page

A simplified walkthrough of how a browser requests resources and turns them into a page.

STEP 01

Enter a URL

The user types an address or clicks a link. The browser identifies the destination domain.

↓
STEP 02

Find the server

DNS helps resolve the domain name to an IP address, so the browser can reach the right server.

↓
STEP 03

Send an HTTP request

The browser requests a resource, commonly the document for the page. HTTPS protects data in transit using TLS.

↓
STEP 04

Receive the response

The server responds with a status code and content such as HTML. The HTML can reference CSS, JavaScript, images, and fonts, which may trigger more requests.

↓
STEP 05

Parse and render

The browser parses HTML into a DOM, parses CSS into style information, calculates layout, paints pixels, and runs JavaScript as needed.
