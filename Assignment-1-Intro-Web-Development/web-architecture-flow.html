What each component does

Client

The browser or app where a person interacts with the product.

API

A defined interface and set of endpoints used by software components to communicate.

Server

Processes incoming requests and applies application rules.

Database

Persists information so it can be queried and changed later.

Example: A shopping page requests product information from an API. The backend may query the product database, format the results as JSON, and return them. The client then displays the products.

Architecture varies by application; an API is an interface and does not have to be a separate physical server.
