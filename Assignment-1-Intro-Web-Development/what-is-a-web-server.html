What is a web server?

A web server receives requests from clients and returns web resources over HTTP or HTTPS.

THE CORE IDEA

Request in. Response out.

A web server can refer to the software that handles HTTP requests, or the computer/environment where that software runs. It may return a static file (such as HTML or an image) or pass a request to application code that generates a response.

A simple request

BrowserGET /index.html
→
Web serverFind or generate content
→
Response200 OK + content

Commonly used web servers

Apache HTTP Server

A widely used open-source web server with a modular configuration system. Often serves static files and can work with application runtimes.

Nginx

A web server and reverse proxy commonly used to serve static content, route traffic, and distribute requests to application servers.

Microsoft IIS

A web server for Windows environments, often used with Microsoft web technologies and enterprise hosting.

Caddy

A modern web server known for straightforward configuration and automatic HTTPS in common deployments.

Node.js HTTP servers

Developers can use Node.js with frameworks such as Express to build application servers that respond to HTTP requests.

Important: The browser is the client. The server is responsible for receiving and responding to the request; application logic and databases may be additional parts of the system.
Web servers connect browser requests to the resources and services a website provides.
