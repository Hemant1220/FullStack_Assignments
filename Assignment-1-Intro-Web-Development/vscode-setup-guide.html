Set up Visual Studio Code for web development

A quick Windows-oriented walkthrough for HTML, CSS, and JavaScript.

01

Download and install

Open the official Visual Studio Code website, download the Windows User Installer, run it, and follow the setup prompts.

02

Create a project folder

Make a folder such as my-first-website. In VS Code, select File → Open Folder and open it.

03

Create the web files

In the Explorer panel, create index.html, style.css, and script.js. Link CSS using a <link> element and JavaScript using a <script> element.

04

Use the editor features

HTML, CSS, and JavaScript have built-in language support. Optional extensions such as Live Server can make previewing local pages more convenient.

05

Preview and test

Open your HTML page in a browser, then use browser Developer Tools to inspect layout, errors, and responsive behavior.
