How the client–server model works

A client asks for a resource or service; a server processes that request and returns a response.

01

Client

Browser on a laptop or phone

Creates an HTTP request
HTTP request →
← HTTP response
02

Web server

Receives and handles the request

Sends back HTML, CSS, data, or an error
Example: When you open a shop website, your browser requests the home page. The server responds with the files the browser needs to display it.

Basic sequence

  1. Request: the client asks for a URL or resource.
  2. Processing: the server locates a file or runs application logic.
  3. Response: the server returns a status code and content.
  4. Display: the client/browser renders the response.
