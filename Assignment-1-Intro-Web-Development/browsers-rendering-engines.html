ASSIGNMENT 1 · Q9

Five web browsers, three major engine families

A browser is the app you use. A rendering engine interprets HTML and CSS, calculates layout, and paints the page.

5

Why engines matter

Different engines implement web standards with different internal code and release schedules. This can affect support for new CSS, HTML, and web APIs, so developers should test sites in more than one browser.

C

Google Chrome

Rendering engine: Blink

Chrome's desktop rendering is built on Blink, part of the Chromium project. It parses HTML/CSS, computes layout, and paints page content. Its JavaScript engine is V8, which is separate from the rendering engine.

F

Mozilla Firefox

Rendering engine: Gecko

Gecko is Mozilla's browser engine. It includes HTML parsing, layout, rendering, networking, and DOM features. Firefox's JavaScript engine is SpiderMonkey, a separate component.

S

Apple Safari

Rendering engine: WebKit

WebKit is the open-source browser engine used by Safari. It handles web content and rendering, while JavaScriptCore runs JavaScript. Safari is especially integrated with Apple platforms.

e

Microsoft Edge

Rendering engine: Blink (desktop)

Modern desktop Edge is Chromium-based and uses Blink for rendering. It shares a broad engine foundation with Chrome, but browser features and configuration can still differ.

O

Opera

Rendering engine: Blink (desktop)

Modern desktop Opera is Chromium-based and uses Blink. This shared engine helps with broad web compatibility, while Opera adds its own browser interface and features.

Remember: rendering engine ≠ JavaScript engine

The rendering engine handles parsing and displaying web content. The JavaScript engine executes JavaScript. They cooperate, but they are not the same component. Also, browser engine details can differ by platform and product version; the list above describes common desktop versions.
