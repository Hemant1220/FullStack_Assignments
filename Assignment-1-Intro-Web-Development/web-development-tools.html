A practical web development toolkit

A basic environment includes tools to write code, preview behavior, manage changes, and run applications.

⌨

Code editor

Example: VS Code

Write and organize HTML, CSS, JavaScript, and configuration files. Syntax highlighting and code completion help spot mistakes.

◉

Web browser

Examples: Chrome, Firefox, Edge

Open the page as a user would see it. Check responsive layouts and cross-browser behavior.

⚙

Developer tools

Built into modern browsers

Inspect HTML and CSS, view console errors, monitor network requests, and test different screen sizes.

⌘

Version control

Examples: Git and GitHub

Track file history, compare changes, collaborate, and store a remote copy of the project.

▣

Local web server

Examples: Live Server, Node.js server

Serve project files locally using an HTTP URL. Useful for projects that need requests or module loading.

{ }

Runtime & package tools

Example: Node.js with npm

Run JavaScript tools outside the browser and manage dependencies when a project needs them. Not required for every simple HTML page.

⇄

API testing tool

Examples: Postman, curl

Send HTTP requests and inspect API responses without building a full user interface first.

✎

Design & documentation

Examples: Figma, MDN Web Docs

Plan layouts, reference web standards, and understand HTML, CSS, browser APIs, and accessibility.

Minimum setup for a first page

  1. Install a code editor.
  2. Use a modern browser with DevTools.
  3. Create index.html and, as needed, style.css and script.js.
  4. Open the page in the browser; add Git when you are ready to track changes.
Choose tools that match the project. A simple static page needs very little setup.
