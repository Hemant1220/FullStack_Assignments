Static and dynamic websites

Both can look polished, but they differ in how content is produced and updated.

PAGE
TYPE 01

Static website

Usually serves pre-written files such as HTML, CSS, images, and JavaScript. The same file is generally sent to visitors until someone updates or redeploys it.

  • Simple to host and cache
  • Often fast with fewer moving parts
  • Good for portfolios, documentation, and brochure sites

Example: A personal portfolio with an About page and project gallery written in HTML.

LIVE DATA
TYPE 02

Dynamic website

Generates or updates content based on user input, stored data, account state, or application logic. It may use a backend and database, and can also update in the browser.

  • Personalized or frequently changing content
  • Can include login, search, carts, or dashboards
  • Requires careful handling of performance and security

Example: An online store that shows an account's orders and current product availability.

A useful distinction

“Static” does not mean plain or non-interactive. A static site can use client-side JavaScript; “dynamic” usually refers to content or responses that vary through application logic or data.

Website type depends on how content and behavior are delivered, not just on visual design.
