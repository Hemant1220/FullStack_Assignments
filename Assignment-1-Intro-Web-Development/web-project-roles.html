ASSIGNMENT 1 · Q6

People behind a web product

Frontend developers, backend developers, and database administrators coordinate to deliver a reliable application.

USER

Uses the website

↕
01

Frontend developer

Interface and user experience

  • Builds pages, navigation, forms, and responsive layouts.
  • Connects the interface to backend APIs.
  • Checks accessibility and browser behavior.

Typical deliverable: Product page and checkout UI.

02

Backend developer

Server logic and APIs

  • Creates endpoints and business rules.
  • Handles authentication and input validation.
  • Requests or updates information in the database.

Typical deliverable: Login endpoint or order API.

03

Database administrator

Data integrity and availability

  • Designs or maintains database structures and access.
  • Manages backups, permissions, and recovery.
  • Monitors performance, reliability, and security.

Typical deliverable: Secure, backed-up database.

How the roles work together

The frontend sends a request to an API. Backend code validates the request and queries the database. The database returns records, backend logic prepares a response, and the frontend presents the result to the user. In smaller teams, one person may cover multiple roles.

Successful projects depend on clear ownership and collaboration.
