With box-sizing: border-box, the declared width includes the content, padding, and border.

Margin — outside space around an element.

Border — the visible edge.

Padding — space between content and border.

Content — the text, image, or other content.

Using a consistent box-sizing model makes layout sizing easier to reason about.
