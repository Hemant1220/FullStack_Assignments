# Assignment 5 — JavaScript Functions

This folder contains separate solutions for all 9 questions in the uploaded assignment.

## Files

1. `q01-callback-greeting.js` — callback function and greeting flow.
2. `q02-higher-order-function.js` — `applyOperation()` to double and square values.
3. `q03-arrow-function-this.js` — arrow function `this` behavior and normal-function fix.
4. `q04-car-prototype.js` — constructor function and shared prototype method.
5. `q05-person-student-prototype-inheritance.js` — Person-to-Student prototype inheritance.
6. `q06-person-faculty-professor-chain.js` — three-level prototype chain.
7. `q07-closure-make-multiplier.js` — closures with reusable multiplier functions.
8. `q08-array-my-map.js` — custom `Array.prototype.myMap()`.
9. `q09-person-student-es6-classes.js` — ES6 class inheritance using `extends` and `super()`.

## Run a solution

Use Node.js from this folder:

```bash
node q01-callback-greeting.js
```

Run each question file separately. The assignment uses core JavaScript (ES6+) without frameworks or external libraries.
