THE CSS BOX MODEL

Same width. Different outcome.

Compare how padding and borders affect the final rendered width.

DEFAULT

content-box

CSS width: 240px

Padding: 24px

Border: 6px

The declared width covers only the content. Padding and borders are added outside it, making the total width 300px.

RECOMMENDED

border-box

CSS width: 240px

Padding: 24px

Border: 6px

The declared width includes content, padding, and borders, so the total width remains 240px.

Tip: box-sizing: border-box; makes sizing easier to predict in responsive layouts.
