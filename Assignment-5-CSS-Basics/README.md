# Assignment 5 — CSS Basics

This folder contains all ten questions from the CSS Basics assignment. Each question has a descriptive HTML file and a matching CSS file. The examples use semantic HTML and plain CSS only — no JavaScript or external frameworks.

6. [CSS-Only Photo Gallery](css-photo-gallery.html)

## View the pages
Open any HTML file in a browser and keep its matching CSS file in the same directory. Remote image examples need an internet connection. Forms are front-end demonstrations and do not submit to a real service.
