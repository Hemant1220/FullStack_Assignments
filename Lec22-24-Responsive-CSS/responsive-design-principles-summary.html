THE FOUNDATIONS

Responsive design, explained

Three principles that help a website work on any screen.
↔

Fluid Layouts

Use flexible proportions so content grows or shrinks with the viewport instead of fixed widths.

width: min(100%, 72rem);
▧

Flexible Media

Keep images and videos inside containers to prevent overflow on small screens.

img { max-width: 100%; height: auto; }
⌁

Breakpoints

Use media queries when the design needs to change to stay readable and easy to navigate.

@media (max-width: 600px) { ... }
Build flexible first. Refine where it matters.
