Responsive CSS Cheat Sheet

Six concepts for layouts that work everywhere.

Filters

Adjust the visual appearance of an image.

filter: grayscale(100%);

Media Queries

Apply styles when the viewport matches a condition.

@media (max-width: 700px) { ... }

Responsive Design

Let content and layout adapt to different screens.

width: min(100%, 70rem);

Typography

Scale text fluidly while keeping it readable.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Create flexible two-dimensional layouts.

grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

Transitions

Make visual changes feel smooth and intentional.

transition: transform .25s ease;
Keep it fluid. Test it on real screens.
