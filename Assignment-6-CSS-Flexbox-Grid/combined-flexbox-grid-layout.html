DESIGN · LEARNING · IDEAS

Make room for better ideas.

A useful digital experience begins with a clear purpose, thoughtful structure, and enough space for the important things to stand out.

Flexbox and Grid are complementary CSS layout tools. Flexbox is useful for arranging items along one axis, while Grid makes it easier to structure rows and columns together. Using the right tool for each part of a page can make a layout easier to maintain.

Build from the content outward

Begin by deciding what readers need to know. Use semantic HTML to represent the structure, then apply CSS Grid to divide the page into major regions and Flexbox to align related elements inside those regions.

Finally, test the page at narrower widths. A responsive layout should preserve meaning and reading order rather than simply shrink everything down.

QUICK NOTES

Layout toolkit

  • Grid: page regions and two-dimensional layouts.
  • Flexbox: navigation bars and rows of components.
  • Media queries: responsive changes at breakpoints.
